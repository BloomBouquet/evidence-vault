## Runtime verification

Required commands:

```bash
pnpm install
pnpm test:run
pnpm build
```

The ChatGPT execution sandbox cannot resolve the public npm/GitHub package endpoints in this session, so runtime verification is delegated to `.github/workflows/ci.yml` on the migration PR. A missing `pnpm-lock.yaml` is generated by the runner and uploaded as a one-day artifact so it can be committed before the migration task is considered complete.

The migration is not considered production-verified until GitHub Actions reports the unit tests and production build as successful and the generated lockfile is committed.
